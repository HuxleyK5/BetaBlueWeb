# Pokémon Beta Blue 0.15.0-beta

This beta milestone completes the planned Phase 1–15 architecture pass. It includes the connected Beta Region prototype, Pokémon data and encounters, battles and capture, NPCs and quests, items and shops, evolution and breeding, versioned saves, dynamic world events, and an offline multiplayer foundation.

Phase 15 adds cached map rendering, cached/preloaded assets, procedural sound cues with silent fallback, F3 performance diagnostics, complete play-time tracking, safe-shutdown autosaving, crash reports, automated validation, regression tests, and a reproducible Windows packaging script.

Known limitations:

- Multiplayer is local protocol infrastructure only; no public server exists.
- The content database intentionally contains a small playable subset of species.
- Final character, environment, UI, music, and sound artwork remains production work.
- Pokémon branding and existing sprite rights must be resolved before public or commercial distribution.
